# Сканер документов из видео

Веб-приложение для учёных: загрузите на телефоне или компьютере видео обзора документа (в т.ч. низкого качества), получите восстановленный полный текст и скачайте в **PDF** и **DOCX**.

## Возможности

- Работает в браузере на мобильном и ПК (можно добавить на главный экран как PWA)
- Загрузка видео из галереи или съёмка камерой
- Извлечение кадров с настраиваемым интервалом
- Улучшение изображения для OCR при плохом качестве
- Распознавание текста (Tesseract: русский, английский)
- Объединение текста с нескольких кадров и восстановление пропусков по контексту
- Экспорт: **PDF** и **DOCX**
- Всё обрабатывается локально — без отправки на сервер

## Запуск

```bash
npm install
npm run dev
```

Откройте адрес из терминала (обычно `http://localhost:5173`) на телефоне в той же Wi‑Fi сети — используйте IP компьютера вместо `localhost`.

## Сборка для размещения в интернете

```bash
npm run build
```

Папка `dist/` — загрузите на любой хостинг (GitHub Pages, Netlify, свой сервер).

## Советы для лучшего результата

1. Держите камеру ровно, документ в кадре крупно
2. Избегайте сильных бликов и смаза
3. При длинном видео увеличьте интервал кадров (2–3 сек)
4. После распознавания проверьте текст в поле результата и при необходимости отредактируйте перед экспортом

## Ограничения

- Тяжёлые видео и много кадров нагружают телефон — рекомендуется до ~2–3 минут обзора
- Кириллица в PDF может отображаться латиницей в некоторых просмотрщиках; полная кириллица надёжнее в **DOCX**
- Сложное восстановление рукописного или сильно размытого текста может потребовать ручной правки
